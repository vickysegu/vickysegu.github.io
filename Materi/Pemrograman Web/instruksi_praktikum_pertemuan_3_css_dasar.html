Persiapan Lingkungan Kerja & Struktur Folder

Sebelum menulis kode CSS, pastikan folder proyek Anda tersusun rapi di dalam Visual Studio Code (VS Code) agar jalur pemanggilan file (href="css/style.css") tidak terputus:

  1. Buka VS Code, lalu pilih menu File > Open Folder dan arahkan ke folder proyek-umkm/.
  2. Buat sebuah folder baru bernama css di dalam folder proyek tersebut.
  3. Di dalam folder css, buat sebuah file baru bernama style.css.
  4. Pastikan susunan folder di panel kiri VS Code terlihat persis seperti bagan di bawah ini:
proyek-umkm/
index.html (File HTML utama)
css/
style.css <-- File CSS hari ini
img/
produk-1.jpg

Langkah-Langkah Praktikum Terbimbing (css/style.css)

Kerjakan 5 tahap di bawah ini secara berurutan di dalam file css/style.css. Klik tombol Simulasikan Tahap untuk melihat perubahan tampilannya secara langsung!

Pratinjau:
T1

Tahap 1: Reset Box-Sizing, Tipografi Dasar & Wadah Utama (10 Menit)

Mengunci ukuran kotak dengan box-sizing: border-box, mengganti font halaman, dan menengahkan wadah utama.

/* =========================================================
   TAHAP 1: PENGATURAN DASAR & TIPOGRAFI HALAMAN
   ========================================================= */
* {
  box-sizing: border-box;
}

body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  background-color: #f8fafc;
  color: #0f172a;
  line-height: 1.6;
  margin: 0;
  padding: 20px;
}

/* Membatasi lebar konten utama maksimal 860px dan menengahkannya */
.header-toko,
.nav-toko,
main,
.footer-toko {
  max-width: 860px;
  margin-left: auto;
  margin-right: auto;
}

h1, h2, h3 {
  margin-top: 0;
  color: #1e1b4b;
}
Titik Cek 1: Simpan (Ctrl + S) dan muat ulang browser Anda. Pastikan jenis huruf halaman berubah menjadi Sans-Serif yang bersih dan seluruh konten berada rapi di tengah layar.

Bagian 3 • Estimasi 15 Menit

Inspeksi Box Model via Browser DevTools & Troubleshooting

Eksperimen Wajib di Browser

Cara Memeriksa Diagram Box Model (F12)

  1. Klik kanan pada salah satu Kartu Produk UMKM di browser Anda, lalu pilih Inspect (atau tekan tombol F12).
  2. Pada panel kanan DevTools, gulir ke bagian bawah tab Styles atau klik tab Computed hingga terlihat diagram kotak berlapis.
  3. Arahkan kursor mouse ke setiap lapisan kotak untuk melihat sorotan warna di layar halaman:
    Biru: Content (Isi)
    Hijau: Padding (Dalam)
    Kuning: Border (Tepi)
    Oranye: Margin (Luar)
Klinik Troubleshooting Pemula

Solusi Cepat Jika Kode CSS Tidak Muncul

1. Halaman masih hitam-putih polos seperti Pertemuan 2

Periksa tag <link rel="stylesheet" href="css/style.css"> di dalam <head> file index.html. Pastikan nama folder css dan file style.css ditulis dengan huruf kecil semua.

2. Salah satu baris properti CSS (misal warna atau padding) diabaikan

Periksa baris tepat di atasnya di dalam style.css. Pastikan Anda tidak lupa menuliskan tanda titik koma (;) di akhir setiap deklarasi.

3. Gaya pada .kartu-produk tidak berdampak ke HTML

Di dalam file style.css nama class wajib diawali tanda titik (.kartu-produk), sedangkan di dalam atribut HTML ditulis tanpa titik (class="kartu-produk").
